# What Is Social Media Costing You?
### 30-Minute Interactive Workshop & Live Slidev Deck

An interactive workshop presentation built on [Slidev](https://sli.dev/) and Node.js WebSockets, featuring:
- **15 slides tailored for 30 minutes** (warmup, prediction, empirical study synthesis, behavior change).
- **Live QR code** on Slide 1 for the audience to join on smartphones.
- **Real-time synchronized mobile web app** with instant live translation in 4 languages (**English, German, Spanish, French**).
- **Live interactive socket widgets**: screen time estimates, room histogram, open word cloud for reclaimed time, habit triggers, phone friction ideation wall, 7-day experiment picker, and Gollwitzer IF-THEN implementation intention rules.

## Quick Start (with pnpm)

```bash
# 1. Install dependencies
pnpm install

# 2. Run both the Slidev deck & Socket Server concurrently
pnpm start
```

- **Slidev Presentation Deck**: [http://localhost:3030](http://localhost:3030)
- **Audience Mobile Companion App**: `http://<your-ip>:4000` (auto-generated in QR code on slide 1)
- **Presenter Remote Control**: Slidev built-in presenter mode available at [http://localhost:3030/presenter](http://localhost:3030/presenter)

## Evidence Covered

- **Nguyen et al., 2025 (*Psychological Bulletin*)**: 71 studies, 98,299 participants on short-form video, cognition, attention ($r = -.38$), and inhibitory control ($r = -.41$).
- **Ahmed et al., 2024 & Du et al., 2024**: Meta-analyses on problematic use vs passive screen time, anxiety ($r \approx .39$), and FoMO ($r \approx .50$).
- **2025 Sleep Umbrella Review**: 867,003 adolescents on sleep disruption.
- **Castelo et al., 2025 (RCT)**: 2-week mobile internet restriction leading to attention improvements and 91% participant gains, with opportunity costs shifting to face-to-face socializing, exercise, and nature.
- **May et al., 2025**: 10 randomized trials meta-analysis on depressive symptoms reduction.
- **What Evidence Does NOT Show**: Debunking IQ decline (Sauce '22), brain damage claims (Nivins '24), and panaceas (Lemahieu '25).
